### 1. 总结

线程共享：堆、方法区

线程私有：本地方法栈、虚拟机栈、、程序计数器



### 2. 堆

存储所有对象和数组

GC管理的主要区域

分代设计

年轻代：新对象分配区，分为eden和两个survivor

老年代：存活对象时间长的

### 3. 方法区

存储类信息、常量、静态变量等

### 4 虚拟机栈

存储栈帧，每个方法执行时都会创建一个栈帧，而栈帧，包括局部变量、方法出口等

### 5. 本地方法栈

和虚拟机栈类型，只是调用的是native方法

### 6. 程序计数器

记录当前线程执行到的字节码行号



### 7. 运行时常量池

他是方法区的一部分，存放常量（比如字符串常量），在jdk7之后被移到了堆中

```java
// s1会在常量池创建一个对象，s2要看在常量池中是否已经有"ab"如果没有则会创建两个，一个是"ab"，new 关键字又会创建一个，里面的char[] 指向常量池中新创建的"ab",s3只会创建一个对象，因为在编译器就可以确定常量
String s1 = "ab";
String s2 = new  String("ab");
String s3 = "a"+"b";
```
